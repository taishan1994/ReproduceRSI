# ReproduceRSI

基于 RSI 的 LLM Benchmark 自动复现项目。整体设计见 [架构文档](framework.md)。

目前提供一个零第三方依赖的离线评估原型：记录条件及证据状态，检查实验实际条件和有效性，计算均值与相对误差；单轮结果不计算标准差，并明确标注其证据强度。经验库保存跨任务可搜索的成功/失败案例，并标明适用范围、证据和置信度；假设不会被提升成确定根因。示例数据均为虚构，不代表实测。

## 快速开始

需要 Python 3.8 或更高版本：

```shell
python -m autoreproduce examples/spec.json examples/runs.json -o report.json
python -m autoreproduce.knowledge vllm cuda-graph throughput
python -m unittest discover -s tests
```

实验规范的 `conditions` 为需要核查的条件，状态可为 `explicit`、`derived`、`assumed`、`unknown`、`conflicting`；明确条件须附 `evidence`。每次运行须提供唯一 `run_id`、实际条件、指标和 `valid`。请将 GPU、模型及版本、量化、框架及版本、工作负载和指标定义等关键条件全部写入规范；程序不会自动发现遗漏的条件。只比较参考资料明确提供的指标。

评估首先检查无效实验和未解决条件，再比较均值与容差。规范可通过 `repeats: 1` 明确采用单轮；报告将写入 `measurement_strength: single_run`，标准差为 `null`，不声称重复测量稳定性。多轮结果仍可按均值和标准差汇总。有假设或条件差异时至多标记为近似复现；条件匹配且均值达标也只标记为初步复现，因为当前没有统计检验、正确性自动验证或完整条件审计，不能宣称严格复现。`valid` 和实际条件依赖使用者提供的证据。

当前尚未实现资料自动提取、GPU 调度、部署、基准执行、自动根因诊断、经验自动归纳或经回归验证的 RSI 策略学习；目前经验记录和检索由人审核，规划器可带出历史线索。后续能力应在隔离环境、资源配额和条件锁定机制完善后逐步接入。不要将凭据放入实验规范或报告。

## 经验库与 RSI 迭代

每轮实验前按框架、模型、并行方式、负载和问题搜索 `knowledge/experiences.json`，将命中的条目作为待核对线索。每次完成后把结果记为 `confirmed`、`failed_attempt` 或 `hypothesis`，同时保存证据路径和适用范围；根因未经过单变量对照时只能记为假设。检索器只按关键词排序，不会把经验自动当作当前环境事实。经验库说明见 [framework.md](framework.md)。

## 项目完成后的文件保留与清理

项目通过完成审查后，先锁定最终报告、规范、启动命令、关键有效测量和可复用失败经验，再清理不再需要的产物。保留足以追溯结论的来源、配置、聚合指标和关键诊断证据；删除可重新生成的缓存、临时控制器文件、重复归档，以及已核验并汇总的逐请求流式明细。更新引用并记录清理范围与释放空间。若文件是否支撑结论尚不明确，先保留。不要批量删除唯一原始证据、用户资料、凭据或项目外共享资源。具体决策流程见 [framework.md](framework.md)。
